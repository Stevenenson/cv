\cventry{24--25 Oct 2026}{InvoiceGuard --- Pre-Payment Invoice Fraud Detection}%
        {ITFest 2026 -- Challenge 4}{Romania}{}{
  Built a desktop app that checks every incoming e-Factura invoice from ANAF's SPV
  before it is paid or imported into accounting software (SAGA, WinMentor), giving
  a clear, explained verdict: Verified, Review, or Blocked.
  \begin{itemize}
    \item Designed an explainable \textbf{fraud-detection rule engine} that catches changed IBANs (vs.\ contract and payment history), look-alike ``clone'' suppliers, duplicate invoices, and unusual amounts, with a 0--100 risk score.
    \item Integrated the \textbf{ANAF public API live} to verify that suppliers exist, are active, match their CUI and are registered for VAT --- respecting rate limits (100 CUIs/request, 1 req/s) with a 6-hour cache and offline fallback.
    \item Built a \textbf{hardened XML parser} for the official e-Factura format (UBL 2.1 / CIUS-RO) using defusedxml to block XXE and XML-bomb attacks; validated CUI check digits and IBAN checksums.
    \item Shipped a cross-platform desktop app (pywebview, Windows/macOS) on a local FastAPI server --- all data stays on the accountant's machine, ANAF being the only external call --- plus a web demo and a Chrome extension.
  \end{itemize}
  \small{\textit{Tech: Python, FastAPI, pywebview, JavaScript, HTML/CSS, httpx, defusedxml, ANAF API, Chrome Extension}}
